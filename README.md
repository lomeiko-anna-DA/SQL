# SQL_repo
SQL Business Cases
Developed a collection of analytical SQL queries focused on product, financial, and marketing metrics.

Core Tasks: Analyzed email funnel conversions (Email_&_Account_Analytics), tracked cumulative revenue vs. daily targets (Prediction_Fulfillment), and segmented session traffic with cross-platform revenue distribution.

Tech Stack Applied: Advanced Queries, Window Functions, Table Unification (UNION ALL), Multi-layer Subqueries, Complex Data Aggregations, Data Jointure (JOIN).
